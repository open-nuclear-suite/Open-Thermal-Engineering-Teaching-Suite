SYSTEM REQUIREMENTS

- 64-bit Windows 10 or Windows 11
- A local Windows desktop session

Python does not need to be installed. Each executable includes its own
Python runtime and required software libraries.

RUNNING THE APPLICATIONS

Double-click PVT-Demonstrator.exe to open the thermodynamic-property
demonstrator.

Double-click Boiler-Furnace-Simulator.exe to open the boiler-furnace
teaching simulator.

The first launch may take several seconds because each standalone
executable must unpack its bundled runtime. Windows may also display a
Microsoft Defender SmartScreen warning because the files are not
digitally signed. Verify the SHA-256 checksums in SHA256SUMS.txt before
running the applications.

IMPORTANT SAFETY NOTICE

This software is intended only for conceptual exploration and classroom
demonstration. It is not suitable for equipment design, safety analysis,
certification, operator training, or plant operation.

The boiler-furnace simulator uses simplified educational approximations.
It is not a complete, validated, or standards-conforming implementation
of IAPWS-IF97.
